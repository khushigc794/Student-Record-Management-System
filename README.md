# Student Record Management System

## Project Description
A menu-driven Student Record Management System developed using C programming.

The project uses a Singly Linked List for dynamic memory allocation and management of student records.

## Features
- Add student records
- Delete records by roll number or name
- Display student records
- Modify student details
- Sort records by name or percentage
- Reverse student records
- Delete all records
- Save and load records using file handling

## Technologies Used
- C Programming
- Singly Linked List
- Dynamic Memory Allocation
- File Handling
- GCC Compiler
- Ubuntu Linux
